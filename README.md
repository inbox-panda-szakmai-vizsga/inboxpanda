# InboxPanda

Weboldalba építhető élő chat és kapcsolatfelvételi űrlap, közös jegykezeléssel. A vállalkozás munkatársai weben vagy mobilon válaszolhatnak a megkeresésekre. A szolgáltatás tervezett webcíme az `inboxpanda.site`.

| Mappa | Tartalom |
| --- | --- |
| [docs/openapi](docs/openapi/) | A Laravel REST API OpenAPI-szerződésének helye. |
| [docs/design](docs/design/) | Fejlesztési terv és rendszertervezési dokumentumok. |
| [docs/database](docs/database/) | Adatmodell és ER-diagram. |
| [docs/testing](docs/testing/) | Teszttervek és tesztjegyzőkönyvek. |
| [docs/exam](docs/exam/) | Témaválasztás és vizsgához beadandó dokumentumok. |
